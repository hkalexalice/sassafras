Server-Side Book Structure

This app dynamically loads books directly from your project folders on the server. To add Book 2, Book 3, or more, follow these 3 simple steps:

Step 1: Create folders on server book/2/context/chapter1.js ... chapter16.js
book/2/quiz/quiz1.js ... quiz16.js
Step 2: Register in book/books.json 
{
  "id": "2",
  "title": "Monsters and Mold",
  "series": "Book 2",
  "emoji": "🍄",
  "totalChapters": 16
}
Step 3: Deploy to Netlify Push to Git or upload to Netlify. The new book will automatically appear in the Book dropdown!
